# Synthetic data

Every alert, asset, IP address, site, finding ID, and runbook in this directory is fictional. The samples model common OT monitoring fields without copying client data or a vendor export.

`alerts.json` contains five scenarios:

1. Unexpected outbound communication
2. Asset availability loss
3. Vulnerability prioritization
4. Degraded network traffic
5. Prompt-injection-like text inside monitoring data

`runbooks.json` is the local retrieval corpus. Each entry has a stable ID, tags, safe analyst actions, prohibited actions, and a human escalation target.
